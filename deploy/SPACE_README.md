# COVID Trials AI

Ask a question about COVID-19 treatments, vaccines or prevention. Answers are drawn from
ClinicalTrials.gov records and the open-access papers that report them, with every claim
linked to its source and statistics computed in code.

Research information, not medical advice. Source code: https://github.com/Eesterlein/covid-trials-ai
